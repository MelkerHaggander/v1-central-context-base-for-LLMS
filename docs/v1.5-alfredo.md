## Hur fungerar lösningen?

Flödet är **LLM → MCP på Vercel → Melkers minnesfunktioner → Supabase i Stockholm**.

MCP är adressen ni klistrar in i Claude, ChatGPT, Grok eller Kimi. OAuth är inloggningsfönstret. Databasens åtkomstregler skiljer användarnas minnen åt. Tokenen går inte ut, så ni ska inte behöva logga in om och om igen.

Tre verktyg, inga fler: `save_memory`, `search_memory`, `update_memory`. Ägare = inloggning. Klienten skickar aldrig ett användar-id.

| Klient | Vid koppling | När minnet anropas |
| --- | --- | --- |
| Claude | Öppnar inloggning | Använder token |
| Grok | Öppnar inloggning (HTTP 401) | Använder token |
| Kimi | `kimi mcp auth` | Använder token |
| ChatGPT | Visar verktygen utan token (Mixed) | Öppnar inloggning vid första anropet |

Live just nu för V1.5 är **experiment-Verceln** (Stockholm). Koden för ihopkoppling ligger på `integration/v1.5`.

| Vad | Adress |
| --- | --- |
| App / inloggning | https://v1-alfredo-experiment.vercel.app |
| Anslut-sidan | https://v1-alfredo-experiment.vercel.app/anslut |
| MCP | `https://v1-alfredo-experiment.vercel.app/api/mcp` |

Health ska visa `"mcp":"1.5.0"`, `"chatgpt":"mixed-auth"`, `"grok":"oauth-first"`, `"mcpAuth":"lifetime"`.

Använd **inte** en adress med `-git-` i namnet till ChatGPT eller Grok. Vercel-inloggning stoppar deras servrar.

## Så kan ni testa

1. Öppna [appen](https://v1-alfredo-experiment.vercel.app) och logga in med **ert** testkonto.
2. Gå till [Anslut](https://v1-alfredo-experiment.vercel.app/anslut). Kopiera MCP-adressen. Använd samma konto när ni godkänner kopplingen.
3. Koppla **en** klient:
   - **Claude Desktop:** Settings → Connectors → Add custom connector. Fjärranslutning. Klistra in MCP-adressen. Ingen projektprompt.
   - **Grok (grok.com):** New Connector → Custom → samma adress. Inloggningen ska öppnas av sig själv, som i Claude.
   - **ChatGPT:** Settings → Apps → skapa appen från MCP-adressen. Authentication = Mixed. Ny chatt → Plus → Developer mode → slå på appen i just den chatten.
   - **Kimi Code:** `kimi mcp add --transport http --auth oauth central-memory https://v1-alfredo-experiment.vercel.app/api/mcp` och sedan `kimi mcp auth central-memory`.
4. Skriv: ”Vi har beslutat att lansera den 20 oktober.”
5. Gå till fliken Minnen. Raden ska synas.
6. Ny chatt: ”När ska vi lansera?” Klienten ska söka själv.
7. Ändra datumet. Samma rad ska uppdateras, inte en dubblett.

Ni behöver testlänken och ert testkonto. Ingen administratörsåtkomst till Vercel eller Supabase. Använd påhittade uppgifter under testningen.

## Hur har det verifierats?

- Claude: spara, söka och uppdatera mot samma konto. Andra konton ser inte raden.
- ChatGPT: verktygen syns före inloggning (Mixed). Tokenen behandlas inte som utgången.
- Grok: utan den här koden listades verktygen utan inloggning. Med den öppnas inloggningen (HTTP 401 med `WWW-Authenticate`).
- `npm test` i `apps/api`: 50 tester gröna.

## Vad behöver andra veta?

- Använd senaste MCP-adressen ovan och **ert eget** testkonto.
- Klistra inte in Claude-instruktioner i ett projekt. MCP-servern skickar dem själv.
- Alla chattar sparas inte automatiskt. Klienten sparar när något ska ligga kvar (beslut, mål, deadline, faktum, preferens).
- ChatGPT och Grok måste peka på `/api/mcp`, inte `/api/health`.
- `integration/v1` rörs inte. V1.5-koden som synkar fler LLM:er ligger på `integration/v1.5`. `main` rörs inte.
